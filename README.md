# Journa NextGen - Trading Calendar Dashboard & MT5 Sync 📈

**Journa NextGen** គឺជាកម្មវិធី Trading Journal Dashboard ជំនាន់ថ្មី ដែលរចនាឡើងយ៉ាងផ្ចិតផ្ចង់តាមបែប Minimalist Dark Glassmorphic ជាមួយប្រតិទិនបង្ហាញការជួញដូរប្រចាំខែ (Trading Calendar) អាចដំណើរការបានទាំងលើ **Windows** និង **iOS (iPhone/iPad)** ព្រមទាំងអាចភ្ជាប់ទិន្នន័យពី **MetaTrader 5 (MT5)** ដោយស្វ័យប្រវត្តិ។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

1. **Trading Calendar Dashboard (Day 1 on Monday Style)**:
   - ប្រតិទិនជួញដូររត់ចាប់ពីថ្ងៃទី ១ រហូតដល់ចុងខែយ៉ាងរលូន
   - ថ្ងៃចំណេញ (**Profit**) បង្ហាញពណ៌បៃតង Neon Glow
   - ថ្ងៃខាត (**Loss**) បង្ហាញពណ៌ក្រហម Coral Red Glow
   - កាតសរុបប្រចាំខែ (**Monthly Total SUM**)
   - កាតសរុបប្រចាំឆ្នាំ (**Annual Total ROI & Win Rate**) លើបន្ទាត់តែមួយគ្មានប្រអប់ទទេខណ្ឌកណ្តាលឡើយ
2. **Key Metric Indicators (KPIs)**:
   - **Starting Capital**: ដើមទុនចាប់ផ្តើម (អាច Edit បានភ្លាមៗ)
   - **Monthly Net P&L**: Net Profit/Loss ប្រចាំខែ និង Balance
   - **Total Trades**: ចំនួន Trade សរុប ព្រមទាំងបែងចែក W • L • BE
   - **Win Rate**: គិតជា % ជាមួយ Progress Bar
   - **Profit Factor**: Gross Win vs Gross Loss
3. **ការភ្ជាប់ជាមួយ MetaTrader 5 (MT5 Sync Options)**:
   - **Direct MT5 Account Login**: បញ្ចូល Account Login, Password, និង Server Name ដើម្បី Sync ដោយស្វ័យប្រវត្តិ
   - **1-Click Quick Windows Terminal Sync**: ទាញទិន្នន័យពី MT5 Desktop Terminal ដែលកំពុងបើកលើកុំព្យូទ័រ
   - **Auto-Sync Expert Advisor (EA)**: ដាក់ File EA ចូល MT5 ដើម្បីឱ្យវាផ្ញើ Trade មក App រាល់ពេលបិទ Order
   - **Import Statement (HTML/CSV)**: Drag & Drop File Report ពី MT5
4. **iOS & Mobile PWA Ready (100% ឥតគិតថ្លៃ)**:
   - ឌីហ្សាញឆ្លើយតបយ៉ាងល្អឥតខ្ចោះលើ iPhone / iPad
   - អាចចុច "Add to Home Screen" លើ Safari ដើម្បីប្រើជា App ពេញលេញលើ iPhone ដោយមិនបាច់បង់ $99 ទៅ Apple!

## 🚀 របៀបដំណើរការលើ Windows

គ្រាន់តែ Double-click លើ File:
```
start_dingjourney.bat
```
Server នឹងចាប់ផ្តើមដំណើរការ ហើយបើក Web Browser ទៅកាន់ `http://localhost:8000` ដោយស្វ័យប្រវត្តិ។
